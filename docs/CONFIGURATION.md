# Настройки и диагностика

`config.json` находится рядом с main.js. Не заменяй его при обновлении.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| voiceChatKey | G | Клавиша голосового чата |
| listen | hold | hold — удержание; always — постоянное распознавание (риск случайных команд) |
| castMode | click | Режим применения; должен совпадать с настройками игры |
| keys | Q/W/E/R/D/F | Привязки сфер, Invoke и слотов |
| blockKeys | ["invoke"] | Клавиши, блокируемые приложением; [] отключает блокировку |
| microphone | "" | Системный микрофон или имя устройства |
| expandedVocabulary | автоматически | false отключает V2 |
| phrases | встроенные | Пользовательские фразы на русском; исходные массивы могут переопределяться |
| port | 3055 | Локальный порт GSI и интерфейса |
| authToken | voice_invoke | Токен GSI; setup-dota.ps1 синхронизирует его с конфигурацией игры |
| keyDelayMs | 35 | Исходный интервал |
| castDelayMs | 90 | Исходная пауза без GSI |
| clickDelayMs | 60 | Исходная пауза |
| altDelayMs | 30 | Исходная пауза |
| chainGapMs | 40 | Исходный интервал цепочки |
| slotWaitMs | 1500 | Тайм-аут ожидания слота |

Все игровые интервалы оставлены без изменений. Не менять их без измерений.

## Проверка
- `log.txt`: выбранная модель, SHA-256, режим аудиозахвата и частота, наличие GSI.
- Если модель не активна: проверь имя файла, расположение и хеш из model-manifest.json. Старая V1 не принимается как V2.
- Если микрофон не работает: проверь разрешения Windows и выбор устройства. При невозможности загрузки AudioWorklet используется ScriptProcessor 2048.
- Если GSI не подключён: закрой и перезапусти Dota через start.bat; проверь порт и cfg. Не проверяй голосовой автоматический ввод в сетевой игре.
- Если приложение не запускается: `node --version`, `npm ci`, `npm test`; ошибка остаётся в консоли.

## Ручной чек-лист RC
Проверить чистую установку, повторный запуск, удаление и восстановление GSI; запуск Electron и Vosk V2; звук уведомлений; отсутствие MLG; микрофон, короткие и длинные фразы, разные ударения, ложные срабатывания и задержку. CI не заменяет реальные проверки на пользовательском ПК.
