# Voice Invoker 1.1.1a

Исправления после 1.1.1:

- Фразы конкретных предметов: поиск по внутреннему имени в актуальном инвентаре, без привязки к одному слоту; старые фразы слотов сохранены.
- Проверка словаря V2 при вводе, подсказки слов по префиксу, проверка конфликтов при сохранении.
- Защита от лишнего ЛКМ при Quickcast, безопасный режим только клавиши для неизвестных слотов при включённой синхронизации. Импорт индивидуальных режимов предметов.
- Восстановление выбора Инвокера через реальный HeroSelect, ожидание подтверждения при наличии GSI selected_unit, отмена подтверждающего клика при ручном вводе.
- Улучшение чтения VDF: literal backslash, UTF-16, комментарии, условные суффиксы; ошибки содержат номер строки. Не импортируются частично прочитанные файлы.
- Диагностика отказов Invoke и сброс прогноза при тайм-ауте, без автоматического повторного каста.

Модель V2 и сохранённые настройки не заменяются. После установки проверь импорт биндов, режимы и HeroSelect. Пять предоставленных конфигураций (три уникальные, LOL и ARROW) воспроизвели ошибку экранирования клавиши консоли и успешно разобраны исправленным парсером. Работа в реальной Dota требует ручной проверки. Внутренний npm SemVer 1.1.1-a, публичная версия 1.1.1a.

- Если голосовой чат Dota не назначен, сохраняется настроенная клавиша прослушивания; остальные бинды синхронизируются. При смене аккаунта заменяются режимы слотов, неизвестный режим не наследует лишний клик предыдущего аккаунта. Регрессионный тест воспроизводит оба пресета без личных файлов.

- Единый поиск аккаунта для ручного и автоматического импорта: ActiveUser имеет приоритет, loginusers.vdf используется только как однозначный резервный источник. Все VDF читаются без записи, тесты покрывают UTF-8/UTF-16 BOM и неоднозначность аккаунтов.
