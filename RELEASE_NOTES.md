# Voice Invoker 1.1.1 — проверочная сборка

Все изменения относительно опубликованной 1.1.0-rc.6. Промежуточная RC7 не выпускалась отдельно; 1.1.1 включает её разработку и последующие исправления.

## Установка

**VoiceInvoker-Setup-1.1.1.exe** — единственный готовый установщик Windows x64. Electron с встроенным Node.js, Koffi, Vosk-browser, UUID и неизменная V2 уже внутри. Node.js, npm и отдельный архив модели не нужны. Закрой предыдущий Voice Invoker через трей, установи новую версию, оставь галочку запуска Dota и Voice Invoker. При обновлении сохраняются пользовательские настройки, повреждённая V2 восстанавливается из установщика. В дальнейшем запуск — через меню «Пуск». Steam и установленная Dota необходимы.

## Голосовое управление

- Индивидуальные галочки всех встроенных фраз для 11 способностей. Встроенные фразы не удаляются, собственные можно добавить, отключить и удалить.
- Пользовательские однословные и многословные фразы из настоящего словаря активной модели; отдельное хранение и восстановление после перезапуска.
- Проверка неизвестных слов и активных конфликтов между способностями и предметами. Отключённую фразу можно назначить другому действию.
- Обычные и подготовительные команды используют один набор активных фраз. Сохраняются 143 встроенные команды, шесть префиксов (858 встроенных сочетаний подготовки) и три профиля.
- Режим теста распознавания без игровых нажатий с текстом и совпавшими командами.
- Экспериментальный frames-per-chunk=3, выключен по умолчанию; временная копия проверенной V2, без изменения оригинала. Выигрыш скорости не измерен.

## Предметы и клавиши

- Восемь голосовых слотов: шесть основных, нейтральный и телепорт. Настраиваемые фразы, клавиша и режим каждого слота; пустой список отключает слот.
- Каст предметов только по свежему GSI при живом Инвокере, доступности предмета и отсутствии перезарядки. Рюкзак и пассивные предметы не применяются.
- Индивидуальный режим конкретного предмета по имени GSI поверх режима слота; голосовая команда остаётся привязана к слоту. Отдельного Blink нет.
- Импорт клавиш Dota и Quickcast без записи в Steam, проверка конфликтов и неподдерживаемых сочетаний.
- Событийное наблюдение за файлом биндов, включая атомарную замену. Без фонового 10-секундного опроса PowerShell.
- Автоматическое применение корректных клавиш после завершения каста, подтверждение нативным хуком и сохранение без перезапуска. Защита ручных настроек, корректное отпускание зажатых клавиш, отмена устаревших голосовых гипотез.
- Раздельные переключатели автосинхронизации, Quickcast и уведомлений. Ручной импорт и копирование параметра -gamestateintegration.

## Диагностика и интерфейс

- Переработанная панель на основе диагностического окна исходного EXE: оригинальный значок и явные статусы готовности, ожидания и ошибок.
- Поиск Steam/Dota, проверка наличия и соответствия файла GSI, параметра запуска работающей игры и сохранённого параметра Steam, получение данных и их свежесть, неверный токен.
- Проверка героя, жизни, слотов, перезарядок и инвентаря, клавиш, режимов каста и причин невозможности импорта.
- Статусы модели, словаря, микрофона, нативного хука, локального сервера и повреждённого конфига.
- Проверка/восстановление собственного GSI после подтверждения, ручной выбор папки Dota. Без принудительного закрытия Steam/Dota и перезаписи их настроек.
- Копирование обезличенного отчёта из окна и трея через Electron; сырые логи доступны отдельно. В отчёт не включаются личные пути, Steam ID, токен, имя микрофона, пользовательские фразы и распознанный текст.
- Безопасная демонстрация анимации Sun Strike без игровых нажатий.
- Автоматическое открытие диагностики при проблемах запуска и интеграции, окно критической ошибки с путём журнала, ограниченное восстановление оверлея.
- Трей с оригинальным значком, активностью каста, уведомлением о биндах, перезапуском, копированием отчёта и открытием журналов.

## Стабильность и данные

- Настройки и новые журналы перенесены в %APPDATA%\VoiceInvoker. Миграция RC6/старых RC7 из той же папки без перезаписи существующих данных; старый конфиг сохраняется.
- Атомарное сохранение JSON, резервная копия повреждённого конфига, сохранение неизвестных полей; повторное открытие показывает сохранённые настройки.
- Ротация текущего/предыдущего журнала и журнал лаунчера.
- При отключении микрофона отменяются незавершённые гипотезы и ожидающие команды; восстановление оверлея и штатное завершение нативного потока.
- Дополнительная валидация локальных HTTP-запросов, размера тела, типа содержимого и источника запроса; корректные статусы при ошибках.
- Повторная проверка GSI перед применением слота, тесты push-to-talk и очереди во всех профилях. Сохранены одиночный экземпляр, независимый фоновый запуск и повторное открытие настроек.
- При ошибке GSI штатный BAT открывает приложение для диагностики, а не зависает на ручном вводе пути. UTF-8 для чтения настроек PowerShell.

## Установщик, зависимости и CI

- Electron 45.5.0, Koffi 2.16.3, Vosk-browser 0.0.8, транзитивный UUID 11.1.1 в закреплённом lock-файле.
- Проверка встроенного Electron/Node, загрузки нативного Koffi, наличия Vosk и версий зависимостей; проверка V2 по размеру и SHA-256. При повреждении runtime предлагается переустановить EXE, при отсутствии Node/npm в исходной сборке — официальный сайт Node.js.
- Один самодостаточный NSIS-установщик, запуск приложения и Dota после установки, ярлык меню «Пуск», собственный значок, обновление с сохранением настроек и восстановлением V2.
- Удаление с восстановлением отслеживаемого GSI; изменённая извне интеграция и её резервная копия защищены.
- ESLint, TypeScript checkJs, node:test и покрытие; npm audit блокирует публикацию при уязвимостях средней и выше.
- Windows CI на Node 22/26: нативный хук, фактическое окно диагностики, обновление файла биндов без изменения PID, пользовательские фразы всех способностей, жизненный цикл, установка из EXE, штатный запуск без системного Node в PATH, обновление/восстановление модели и удаление.
- Отдельные этапы компиляции NSIS и тестирования установленной программы, ограниченные тайм-ауты и отмена устаревших прогонов одной ветки.
- Публикация из main только после успешных проверок. SHA-256 установщика приводится ниже при публикации.
