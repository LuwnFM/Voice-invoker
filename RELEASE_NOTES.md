# Voice Invoker 1.1.1a

Исправления после 1.1.1:

- Фразы конкретных предметов: поиск по внутреннему имени в актуальном инвентаре, без привязки к одному слоту; старые фразы слотов сохранены.
- Проверка словаря V2 при вводе, подсказки слов по префиксу, проверка конфликтов при сохранении.
- Защита от лишнего ЛКМ при Quickcast, безопасный режим только клавиши для неизвестных слотов при включённой синхронизации. Импорт индивидуальных режимов предметов.
- Восстановление выбора Инвокера через реальный HeroSelect, ожидание подтверждения при наличии GSI selected_unit, отмена подтверждающего клика при ручном вводе.
- Улучшение чтения VDF: literal backslash, UTF-16, комментарии, условные суффиксы; ошибки содержат номер строки. Не импортируются частично прочитанные файлы.
- Диагностика отказов Invoke и сброс прогноза при тайм-ауте, без автоматического повторного каста.

Модель V2 и сохранённые настройки не заменяются. После установки проверь импорт биндов, режимы и HeroSelect. Реальный файл биндов из проблемной установки не предоставлен, поэтому точная причина ошибки VDF и работа в Dota требуют ручной проверки. Внутренний npm SemVer 1.1.1-a, публичная версия 1.1.1a.
