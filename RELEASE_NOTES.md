# Voice Invoker 1.1.1b

Обновление удобства установки и запуска поверх 1.1.1a.

- `VoiceInvoker-Installer-1.1.1b.exe` — единственный установщик; для ежедневного запуска используется установленный `VoiceInvoker-Launcher.exe`, без консольного окна и системного Node.js.
- Ярлыки рабочего стола и меню «Пуск», необязательный автозапуск с Windows без запуска Dota.
- Повторный запуск установщика той же версии предлагает запустить программу, проверить/восстановить файлы или выйти.
- Проверка SHA-256 файлов перед извлечением: исправные файлы и V2 не перезаписываются, повреждённые и изменившиеся восстанавливаются.
- Обновление зарегистрированной установки на месте. Существующий AppData имеет приоритет; прежние локальные настройки, журналы и запись GSI резервируются. Удаляются известные устаревшие файлы после проверки новой установки; незарегистрированные копии в других папках и посторонние файлы не удаляются.
- Неизменённый GSI и его резервная копия не перезаписываются при запуске.
- Сохранены V2, 143 встроенные фразы, игровые функции, бинды и тайминги 1.1.1a. Реальная игра и микрофон требуют ручной проверки Windows 10/11.
