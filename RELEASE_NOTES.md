# Voice Invoker 1.1.0-rc.1

Release candidate (не стабильный релиз). Модель Invoker V2: 46 102 389 байт, SHA-256 dcba103f27b209415fae50065d420ab59f171bff7da047f60f3801c09de8ba90.

- 143 голосовые команды, 81 исходная сохранена; одиночные «сан», «ката», «катак» исключены, в том числе из старых настроек.
- Пересобранные Gr.fst и HCLr.fst, 44 дополнительных отобранных произношения; акустическая модель исходная.
- AudioWorklet 1024 семпла, fallback ScriptProcessor 2048, без ресемплинга; индекс фраз.
- MLG/хитмаркер удалены, исправлен путь keys.wav.
- Установщик/деинсталлятор GSI, резервное копирование. Игровые тайминги не менялись.
- Модель выбирается автоматически при совпадении SHA-256; исходная модель сохраняется.

## Установка
1. Распаковать исходники в отдельную папку; установить Node.js 22 LTS, если отсутствует.
2. Поместить модель в model/vosk-model-small-ru-invoker.tar.gz.
3. Запустить start.bat; для удаления GSI использовать uninstall.bat. При обновлении сохранить config.json и .dota-install.json, не перезаписывать пользовательский конфиг.
