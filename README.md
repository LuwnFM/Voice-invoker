# Voice Invoker 1.1.1b

Голосовое управление Инвокером в Dota 2 для Windows 10/11 x64. Произнеси название способности, русскую реплику героя или сокращение: приложение распознаёт речь локально и собирает способность, применяет её либо только подготавливает для ручного каста.

**1.1.1b — предварительная версия с новым установщиком и лаунчером поверх исправлений 1.1.1a.** Добавлены фразы конкретных предметов, проверка словаря при вводе, исправления импорта биндов и Quickcast, восстановление выбора Инвокера и диагностика тайм-аутов Invoke. Модель Invoker V2, встроенные фразы и профили задержек сохранены.

[Релизы](https://github.com/LuwnFM/Voice-invoker/releases) · [Что нового в 1.1.1b](RELEASE_NOTES.md) · [Настройки и диагностика](docs/CONFIGURATION.md) · [Полный словарь](docs/COMMANDS.md)

> Автоматизированные игровые действия могут нарушать правила Valve. Проверяй работу в тренировочном режиме; отсутствие санкций не гарантируется. CI не подтверждает качество распознавания твоего голоса или работу в реальном матче.

## Возможности

- Офлайн-распознавание русской речи через Vosk-browser. Записи микрофона не отправляются на сервер.
- 143 встроенные фразы для 11 способностей, включая Cataclysm; собственные фразы, индивидуальные галочки и проверка конфликтов.
- Шесть префиксов подготовки без каста и распознавание нескольких способностей подряд.
- Три профиля Normal, Fast, Turbo; учёт состояния игры, Invoke, слотов и перезарядок через GSI.
- Голосовое управление восемью активными слотами предметов (шесть основных, нейтральный и телепорт) либо конкретным предметом по его внутреннему имени GSI, независимо от текущего слота.
- Обычный каст и Quickcast, импорт режимов слотов и предметов; защита от лишнего клика при неизвестном режиме слота с включённой синхронизацией Quickcast.
- Восстановление выбора своего Инвокера через настроенную клавишу HeroSelect; отмена ожидающего подтверждающего клика при ручном вводе мышью.
- Проверка словаря активной модели при вводе новых фраз и подсказки слов по префиксу.
- Событийная синхронизация клавиш Dota без перезапуска, настройка микрофона, push-to-talk либо постоянное прослушивание.
- Окно диагностики, режим тестирования речи без игровых нажатий, трей, оверлей и источник OBS.
- Самодостаточный Windows-установщик, миграция настроек и восстановление GSI с резервной копией.

## Установка: один EXE

### Требования

| Компонент | Требуется |
|---|---|
| ОС | Windows 10/11 x64 |
| Игра | Steam и установленная Dota 2 |
| Звук | Рабочий микрофон, разрешение Windows на его использование |
| Системные компоненты | Windows PowerShell, WinAPI; tar.exe для опционального экспериментального режима и чтения словаря модели |
| Node.js / npm | Не нужны для установленного EXE; только для исходников |
| Интернет | Для получения установщика и запуска Steam/Dota; распознавание локальное. Для восстановления отсутствующей модели может потребоваться интернет |

1. На странице [релизов](https://github.com/LuwnFM/Voice-invoker/releases) выбери предварительную версию **v1.1.1b** и скачай **VoiceInvoker-Installer-1.1.1b.exe**. Если версия ещё не отображается, проверь [статус сборки](https://github.com/LuwnFM/Voice-invoker/actions). Контрольная сумма SHA-256 указана в описании релиза.
2. Если установлена старая версия, заверши её через трей или Ctrl+Shift+F8. Если она расположена в другой папке, заранее перенеси конфиг по инструкции ниже.
3. Запусти установщик. В нём уже есть Electron с собственным Node.js, Koffi, Vosk-browser, UUID и проверенная V2. Дополнительный ZIP или архив модели не нужен.
4. На последней странице оставь галочку запуска. В дальнейшем открывай ярлык Voice Invoker на рабочем столе или в меню «Пуск» (он запускает `VoiceInvoker-Launcher.exe`, а не установщик). Лаунчер без консольного окна проверяет встроенные компоненты, подготавливает GSI и запускает Steam/Dota с параметрами `-gamestateintegration -windowed -noborder`, если игра ещё не запущена.
5. Если Dota уже работает, её не закрывают автоматически. Для загрузки нового GSI перезапусти игру через лаунчер. При отсутствии Steam/Dota или ошибке GSI приложение открывает диагностику, а не требует ручного ввода пути в консоли.

При повторном запуске установщика той же версии можно запустить установленное приложение без переустановки, проверить/восстановить файлы либо выйти. Исправные файлы проверяются по SHA-256 и не переписываются; повреждённые или изменившиеся восстанавливаются. Автозапуск Windows включается отдельной необязательной галочкой и не запускает Dota автоматически.

Установщик не подписан цифровой подписью. Сверяй источник и SHA-256 перед запуском. Политики PowerShell автоматически не ослабляются. Если скрипт помечен как скачанный, лаунчер может запросить разрешение снять блокировку только с этого файла; корпоративные ограничения требуют решения администратора.

### Проверка перед первой игрой

Открой настройки (Ctrl+Shift+F9), нажми «Считать клавиши Dota», проверь микрофон, клавишу прослушивания, состояние GSI, режимы каста и «Выбрать героя» (HeroSelect). При необходимости сохрани ручные изменения. Включи «Тест распознавания без нажатий», сохрани и перезапусти. Произнеси несколько фраз и проверь текст и совпавшие команды в диагностике. Затем отключи тестовый режим, сохрани и перезапусти для проверки на Инвокере в тренировочной игре.

## Синхронизация с Dota

Автосинхронизация клавиш, Quickcast и уведомления включены по умолчанию и настраиваются отдельно. Программа читает файл `dotakeys_personal.lst` активного аккаунта Steam, отслеживая изменения родительской папки через `fs.watch`. После завершения текущего каста подтверждённые нативным хуком привязки сохраняются в AppData без перезапуска. При конфликте, неподдерживаемой комбинации, неполных данных или сохранённых ручных настройках, ожидающих перезапуска, автоматическое обновление не применяется.

Наблюдение реагирует на сохранение файла игрой. При смене аккаунта открой настройки или начни новый сеанс GSI. Постоянного 10-секундного опроса нет. Можно отключить автоматическую синхронизацию, считать клавиши вручную и сохранить настройки. Steam и его бинды не редактируются; кнопка копирует `-gamestateintegration` для ручного добавления к существующим параметрам запуска.

### Аккаунты Steam и импорт VDF

- Читается `Steam/userdata/<AccountID>/570/remote/cfg/dotakeys_personal.lst`. Активный аккаунт определяется по `ActiveUser` из реестра; если он неизвестен, используется единственный аккаунт либо единственная запись `MostRecent` в `Steam/config/loginusers.vdf` с существующим файлом биндов. При неоднозначности или отсутствующем явно активном аккаунте другой аккаунт не подставляется.
- Поддерживаются обычные и буквальные обратные слеши в KeyValues, комментарии, условные суффиксы и кодировки UTF-8/UTF-16 LE/BE с BOM. При временной блокировке или неполной записи watcher повторяет чтение; синтаксическая ошибка содержит номер строки.
- Если голосовой чат Dota не назначен, сохраняется настроенная клавиша прослушивания, остальные бинды могут синхронизироваться. Постоянное прослушивание не включается из-за одного только отсутствия бинда в игре.
- При успешной синхронизации Quickcast набор импортированных режимов слотов заменяется, а не дополняется режимами старого аккаунта. Индивидуальные бинды героев, неподдерживаемые модификаторы и конфликтующие назначения требуют ручной проверки.

### Обычный каст и Quickcast

При обычном касте целевой способности отправляется клавиша и подтверждающий клик, при Quickcast — только клавиша. При включённых автосинхронизации и синхронизации Quickcast неизвестный режим слота способности использует только клавишу. Для ручного общего обычного каста отключи синхронизацию Quickcast или назначь обычный режим конкретному слоту. Для предметов дополнительно учитывается режим конкретного предмета (см. ниже). Если импорт не удался, предыдущие настройки могут остаться активными: проверь диагностику перед игрой.

## Голосовые фразы и предметы

### Способности

У каждой из 11 способностей в разделе «Голосовые фразы» есть список встроенных и пользовательских фраз. Встроенную фразу можно отключить, собственную — добавить, отключить или удалить. Снятие всех галочек выключает способность. Слова должны входить в словарь активной модели. При вводе редактор проверяет слова, показывает отсутствующие и предлагает варианты по префиксу; функция «Найти слова» ищет в словаре. Зелёный результат означает наличие слов, а не гарантию распознавания произношения. При сохранении проверяются конфликты между активными командами способностей, слотов и конкретных предметов. Отключённую фразу можно переназначить другому действию; её повторное включение при конфликте запрещено. Префиксы подготовки используют тот же активный набор. Изменения фраз требуют сохранения и перезапуска.

### Предметы

В 1.1.1b доступны два независимых способа назначения фраз:

| Раздел настроек | Что делает команда |
|---|---|
| «Фразы для слотов предметов» | Применяет предмет, находящийся в указанном слоте сейчас. При перестановке предметов фраза остаётся у слота. |
| «Фразы конкретных предметов» | Ищет предмет по внутреннему имени GSI (например, `item_rod_of_atos`) среди восьми активных слотов. Фраза следует за предметом при перестановке. |

Чтобы назначить Rod of Atos голосовую команду, нажми «Добавить фразы предмета», введи `item_rod_of_atos` и, например, «корни», если слово доступно в словаре. Вводи по одной фразе на строку. Сохрани изменения и перезапусти приложение. Пустой список отключает команды; одинаковые активные фразы для разных действий запрещены. Если предметов с одним именем несколько, используется первый доступный экземпляр.

В разделе «Индивидуальный режим каста предметов» настраивается только способ нажатия, не голосовые фразы. Слотам можно назначить «Только клавиша» или «Клавиша + клик». При активной автосинхронизации Quickcast импортированный режим конкретного предмета учитывается для слота с быстрым кастом; явно обычный режим слота сохраняется. Если импортированного режима предмета нет либо синхронизация выключена, используется ручное переопределение предмета, затем режим слота. При отсутствии режима слота предмет по умолчанию использует только клавишу. Режимы не изменяют настройки самой Dota.

Для применения нужны свежие данные GSI (менее 5 секунд), живой Инвокер, доступный активный предмет без перезарядки и назначенная клавиша соответствующего слота. Рюкзак, пассивные предметы и подготовка предметов не поддерживаются. Отдельной встроенной команды Blink нет; пользовательскую команду для конкретного предмета можно назначить самостоятельно.

## Подготовка способностей без каста

Можно голосом не только применить способность, но и собрать её заранее, оставив в одном из слотов для ручного применения. Эта возможность работает в **Normal, Fast и Turbo** и не требует переключения отдельного режима.

Удерживай настроенную клавишу прослушивания (G до импорта биндов, если не включено постоянное прослушивание), произнеси префикс перед названием способности и закончи высказывание. Допустимы ровно шесть префиксов:

| Префикс | Пример команды | Результат |
|---|---|---|
| «запиши в фолиант» | запиши в фолиант торнадо | Подготовить Tornado |
| «записать в фолиант» | записать в фолиант метеор | Подготовить Chaos Meteor |
| «подготовить» | подготовить сан страйк | Подготовить Sun Strike |
| «подготовь» | подготовь форжи | Подготовить Forge Spirit |
| «готовь» | готовь стенка | Подготовить Ice Wall |
| «готовить» | готовить эмп | Подготовить E.M.P. |

Любой префикс можно сочетать с любой из 143 фраз в таблице ниже, включая длинные реплики и сокращения. С V2 это 858 комбинаций подготовки в дополнение к 143 обычным командам. Модель не менялась: комбинации добавляются в грамматику при запуске распознавателя. Для пользовательских фраз и штатной модели используются их собственные активные списки.

**Пример с Tornado (стандартные бинды):**

- «Торнадо» — W → W → Q → R → D (и клик при обычном касте); если способность уже в слоте, используется этот слот.
- «Подготовь торнадо» — только W → W → Q → R. Применяешь способность сам клавишей D или F, в зависимости от её слота.

### Как работает подготовка

- При наличии свежих данных GSI уже собранная способность остаётся в своём слоте, без повторного Invoke. Собственная перезарядка способности и невозможность её применения не мешают подготовке; ограничения самого Invoke сохраняются.
- Новая способность собирается сферами и Invoke. Программа ждёт подтверждения от GSI и показывает «Подготовлено: название способности». Клавиши слотов, Alt и клик не отправляются.
- Без свежего GSI отправляются сферы и Invoke, но появление способности не считается подтверждённым. Оверлей сообщает «Invoke отправлен: название способности (нет GSI)».
- «Подготовь катаклизм» подготавливает Sun Strike; Cataclysm автоматически не применяется. Для самого Cataclysm действуют обычные требования игры.
- Один префикс распространяется на последующие способности текущего высказывания: «готовь торнадо метеор» ставит обе подготовки в очередь. Вторая может быть отклонена из-за перезарядки Invoke. Отдельно произнесённый префикс сам по себе ничего не нажимает.
- После окончания высказывания префикс сбрасывается. Для перехода обратно к автоматическому касту закончи текущую реплику и произнеси новую без префикса. Лучше разделять обычные команды и подготовку на отдельные высказывания.
- При обнаруженном префиксе программа не отправляет предварительную гипотезу на применение, а ждёт итог распознавания. Это снижает риск неправильного каста, но не исключает ошибок распознавания речи.

### Скорость и ручное применение

| Профиль | Хоткей | Сферы + Invoke: заданные паузы |
|---|---|---:|
| Normal | Ctrl+Shift+F10 | 105 мс |
| Fast | Ctrl+Shift+F11 | 60 мс |
| Turbo | Ctrl+Shift+F12 | 30 мс |

При подготовке не используются `castDelayMs`, `clickDelayMs` и `altDelayMs`. Таблица показывает только сумму пауз между четырьмя нажатиями, без распознавания, ожидания GSI и межкомандного интервала. Реальная скорость зависит от Windows и игры.

Для ручного применения оставь слоты `slot1` и `slot2` вне списка `blockKeys`. По умолчанию блокируется только Invoke (`["invoke"]`), поэтому D и F доступны. Если раньше блокировал слоты, сними соответствующие галочки в настройках Ctrl+Shift+F9 и сохрани настройки с перезапуском приложения.

Английские названия произноси с привычным русским произношением: в настройках они записаны русскими буквами. Ниже полный список встроенных фраз при активной V2; старые фонетические варианты тоже включены.

## Диагностика

Раздел «Проверка» различает зелёные статусы, ожидание и ошибки. Он проверяет наличие Steam/Dota, установленный GSI, его порт/токен и данные инвентаря, сохранённый и действующий параметр запуска, поступление пакетов и состояние героя, бинды и режимы каста, модель/словарь, микрофон и нативный хук.

| Симптом | Действие |
|---|---|
| Steam или Dota не найдены | Установи Steam/Dota или укажи папку игры в диагностике |
| GSI отсутствует или не соответствует конфигу | «Проверить / восстановить GSI», подтверди и перезапусти Dota |
| Dota запущена, но пакетов нет | Проверь параметр запуска, GSI и вход в тренировочную игру |
| Несовпадение клавиш | Считай бинды, проверь активный аккаунт, конфликты, HeroSelect и Quickcast, сохрани |
| `Missing VDF value` или ошибка чтения биндов | Проверь версию приложения, активный аккаунт Steam и журнал с номером строки; после сохранения настроек Dota повтори импорт |
| После каста выделяется противник | Проверь режимы каста и бинд «Выбрать героя»; см. инструкцию ниже |
| Invoke не подтвердился | Проверь свежесть GSI, доступность Invoke и журнал; приложение не повторяет каст автоматически по тайм-ауту |
| Новое слово отсутствует в словаре | Выбери предложенный вариант либо другую фразу; наличие слова не гарантирует качество распознавания |
| Микрофон недоступен | Проверь разрешения Windows и устройство, перезапусти приложение |
| Модель повреждена | Повторно запусти официальный установщик; либо дождись проверенного восстановления модели |
| Ошибка встроенного runtime | Переустанови официальный EXE; внешний Node.js не исправляет встроенный Electron |
| Порт 3055 занят | Закрой прежний экземпляр или другую программу, использующую порт |

Ручное восстановление GSI меняет только собственный файл интеграции с подтверждением. Внешне изменённый файл не перезаписывается. При ошибке запуска открывается диагностика; при критическом сбое показывается окно с путём журнала. Оверлей восстанавливается после сбоя до трёх раз. Кнопка Sun Strike воспроизводит только анимацию, без игровых нажатий.

Кнопка «Скопировать отчёт» и трей формируют обезличенный отчёт; в нём нет локальных путей, имени микрофона, Steam ID, токена, пользовательских фраз и сырого текста распознавания. Сырые журналы можно открыть отдельно.

### Если после каста выделяется противник

Проверь совпадение обычного каста и Quickcast для обоих слотов способностей и предметов, включая индивидуальные переопределения. Лишний ЛКМ может выделить чужого героя. Считай бинды либо назначь в настройках реальную клавишу Dota «Выбрать героя» (HeroSelect; например, F1 или Space, не подставляется автоматически).

При известной потере выделения следующая команда ждёт подтверждения GSI; если поле выделения отсутствует, после отправленного автоматического ЛКМ выполняется одна попытка вернуть героя перед следующей командой. Ручной ЛКМ/ПКМ в ожидании подтверждающего клика отменяет автоматический клик. Без заданной клавиши HeroSelect автоматическое восстановление не выполняется. Курсор не перемещается, Esc/Stop не используются. Реальная игра требует ручной проверки.

## Настройки, обновление и удаление

Данные находятся в `%APPDATA%\VoiceInvoker`: `config.json`, `log.txt`, `log.previous.txt`, `launcher.log`; при повреждении настроек сохраняется `config.json.broken`. Сохранение JSON атомарное. При первом запуске прежний конфиг из той же папки копируется, только если AppData ещё не содержит настроек. При переходе со старой установки в другой папке скопируй её конфиг вручную до первого запуска. Существующий AppData имеет приоритет. Не удаляй старую запись `.dota-install.json` до восстановления прежней интеграции.

Установщик обновляет зарегистрированную установку на месте, переносит старые настройки в AppData (если там ещё нет конфигурации), архивирует прежние локальные журналы и копию записи GSI в `%APPDATA%\VoiceInvoker\legacy-backups`, сохраняет действующий GSI и удаляет известные устаревшие файлы только после проверки новой установки. Неизвестные пользовательские файлы и незарегистрированные ZIP/portable-копии в других папках не удаляются автоматически. Исправный архив V2 сохраняется; повреждённый восстанавливается. GSI при обычном запуске не перезаписывается, если его содержимое и запись установки уже совпадают. При удалении через меню «Пуск» или параметры Windows восстанавливается отслеживаемый GSI, сохраняются настройки и модель. Если GSI изменён извне, удаление останавливается, не уничтожая резервную копию. Закрытие Dota не завершает Voice Invoker; для выхода используй трей или Ctrl+Shift+F8. Повторный запуск открывает настройки существующего экземпляра, а не создаёт второй.

Основные параметры и интервалы: [CONFIGURATION.md](docs/CONFIGURATION.md). Модель и обычные задержки не изменены. Экспериментальный `frames-per-chunk=3` выключен по умолчанию, создаёт временную копию V2; ускорение не доказано измерениями.

## Запуск из исходников (для разработки)

Скачай исходники через GitHub. Для них нужны Node.js **22.12+ x64** или 26 x64 с npm, PowerShell и интернет для первой установки. [Официальная загрузка Node.js](https://nodejs.org/en/download). При отсутствии Node/npm `start.bat` предлагает открыть официальный сайт. Скрипт проверяет закреплённые версии зависимостей, восстанавливает Electron с проверкой SHA-256, запускает GSI и приложение. V2 загружается с проверкой размера и SHA-256, если её нет. Для готового установщика этот способ не нужен.

```powershell
npm ci
npm run check:runtime
node scripts/fetch-model.js model
.\scripts\build-windows.ps1 -Installer
```

NSIS нужен только для самостоятельной сборки установщика. При сборке выполняется тест установки и удаления. Внутренний параметр SkipInstallerSmoke используется CI, где тест выделен в отдельный обязательный этап.
