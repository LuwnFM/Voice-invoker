# Voice Invoker

Голосовое управление способностями Инвокера в Dota 2 для Windows 10/11 x64. Произноси название способности, русскую реплику героя или привычное сокращение — приложение распознаёт фразу и автоматически собирает и применяет способность либо только подготавливает её для ручного применения, если перед названием произнесён специальный голосовой префикс. Учитываются настройки клавиш и данные игры (GSI).

Текущая версия: **1.1.0-rc.7** (Release Candidate). RC7 добавляет индивидуальный выбор фраз, диагностику, импорт биндов, восемь настраиваемых слотов предметов и опциональный экспериментальный режим Vosk. Фоновая работа RC6 и голосовые возможности RC4 сохранены.

[Скачать релиз](https://github.com/LuwnFM/Voice-invoker/releases/tag/v1.1.0-rc.7) · [Модель на Google Диске](https://drive.google.com/file/d/1inyLlShd7d6Lql1MosCWKGdnPUvmKXZD/view) · [Документация](docs/CONFIGURATION.md)

## Возможности

- Офлайн-распознавание русской речи через Vosk-browser в Electron. Записи микрофона не отправляются на сервер.
- 143 встроенные голосовые команды для 11 способностей, включая Cataclysm, английские названия в русской транскрипции, реплики героя, разговорные и шуточные варианты.
- Голосовая подготовка без каста: шесть префиксов для всех 143 встроенных фраз (858 сочетаний с V2). Не требует переключения режима или отдельного хоткея.
- Три профиля скорости Normal, Fast и Turbo действуют и при автоматическом касте, и при подготовке.
- Распознавание отдельных способностей и нескольких команд подряд, например «торнадо эмп метеор». Приоритет отдаётся более длинным совпадающим фразам.
- Удержание клавиши голосового чата или постоянное прослушивание микрофона; выбор устройства и переназначение клавиш.
- Поддержка обычного каста и quickcast, настраиваемая блокировка ручного Invoke и слотов.
- Получение состояния способностей через Dota Game State Integration (GSI), ожидание появления способности в слоте; при отсутствии данных используется резервный режим.
- Оверлей состояния распознавания, звуковые уведомления и локальный источник для OBS. MLG-видео и хитмаркер отсутствуют.
- Автоматическая установка и обратимое удаление GSI, поиск Dota в библиотеках Steam.
- AudioWorklet передаёт аудио блоками по 1024 семпла; если он недоступен, используется ScriptProcessor с блоками 2048. Частота AudioContext не меняется принудительным ресемплингом.

Использование автоматизированных игровых действий может нарушать правила Valve. Проверяй работу вне сетевых матчей; безопасность аккаунта не гарантируется.

## Установка и запуск

1. Скачай [Source code (zip) текущего релиза](https://github.com/LuwnFM/Voice-invoker/archive/refs/tags/v1.1.0-rc.7.zip) и распакуй архив в отдельную папку.
2. Установи [Node.js 22 LTS x64](https://nodejs.org/en/download), если его ещё нет. На компьютере должны быть Steam и установленная Dota 2.
3. Закрой Dota 2 и запусти `start.bat`. Скрипт при необходимости установит npm-зависимости, найдёт игру, установит GSI и запустит Dota с параметрами `-gamestateintegration -windowed -noborder`, затем приложение. Постоянные параметры запуска Steam и личные бинды не переписываются.
4. При первом запуске модель Invoker V2 скачивается автоматически. Дождись завершения загрузки, проверь настройки клавиш и микрофона. В `log.txt` при успешной проверке модели появится `Invoker V2 (SHA-256 OK)`.

Для первого запуска нужен интернет (зависимости и модель). После установки распознавание работает локально. Если файл помечен Windows как скачанный, установщик спросит разрешение разблокировать только setup-dota.ps1. Соглашайся только для доверенного релиза. Политики PowerShell не меняются; при AllSigned или корпоративной политике потребуется разрешение администратора. Установщик проверяет Electron/Koffi/Vosk, восстанавливает недостающий Electron из кеша или официального архива с проверкой SHA-256. Рекомендуется Node.js 22 x64.

## Подготовка способностей без каста

В RC4 можно голосом не только применить способность, но и собрать её заранее, оставив в одном из слотов для ручного применения. Эта возможность работает в **Normal, Fast и Turbo** и не требует переключения отдельного режима.

Удерживай клавишу голосового чата (G по умолчанию), произнеси префикс перед названием способности и закончи высказывание. Допустимы ровно шесть префиксов:

| Префикс | Пример команды | Результат |
|---|---|---|
| «запиши в фолиант» | запиши в фолиант торнадо | Подготовить Tornado |
| «записать в фолиант» | записать в фолиант метеор | Подготовить Chaos Meteor |
| «подготовить» | подготовить сан страйк | Подготовить Sun Strike |
| «подготовь» | подготовь форжи | Подготовить Forge Spirit |
| «готовь» | готовь стенка | Подготовить Ice Wall |
| «готовить» | готовить эмп | Подготовить E.M.P. |

Любой префикс можно сочетать с любой из 143 фраз в таблице ниже, включая длинные реплики и сокращения. С V2 это 858 комбинаций подготовки в дополнение к 143 обычным командам. Модель не менялась: комбинации добавляются в грамматику при запуске распознавателя. Для пользовательских фраз и штатной модели используются их собственные активные списки.

**Пример с Tornado (стандартные бинды):**

- «Торнадо» — W → W → Q → R → D (и клик при обычном касте); если способность уже в слоте, используется этот слот.
- «Подготовь торнадо» — только W → W → Q → R. Применяешь способность сам клавишей D или F, в зависимости от её слота.

### Как работает подготовка

- При наличии свежих данных GSI уже собранная способность остаётся в своём слоте, без повторного Invoke. Собственная перезарядка способности и невозможность её применения не мешают подготовке; ограничения самого Invoke сохраняются.
- Новая способность собирается сферами и Invoke. Программа ждёт подтверждения от GSI и показывает «Подготовлено: название способности». Клавиши слотов, Alt и клик не отправляются.
- Без свежего GSI отправляются сферы и Invoke, но появление способности не считается подтверждённым. Оверлей сообщает «Invoke отправлен: название способности (нет GSI)».
- «Подготовь катаклизм» подготавливает Sun Strike; Cataclysm автоматически не применяется. Для самого Cataclysm действуют обычные требования игры.
- Один префикс распространяется на последующие способности текущего высказывания: «готовь торнадо метеор» ставит обе подготовки в очередь. Вторая может быть отклонена из-за перезарядки Invoke. Отдельно произнесённый префикс сам по себе ничего не нажимает.
- После окончания высказывания префикс сбрасывается. Для перехода обратно к автоматическому касту закончи текущую реплику и произнеси новую без префикса. Лучше разделять обычные команды и подготовку на отдельные высказывания.
- При обнаруженном префиксе программа не отправляет предварительную гипотезу на применение, а ждёт итог распознавания. Это снижает риск неправильного каста, но не исключает ошибок распознавания речи.

### Скорость и ручное применение

| Профиль | Хоткей | Сферы + Invoke: заданные паузы |
|---|---|---:|
| Normal | Ctrl+Shift+F10 | 105 мс |
| Fast | Ctrl+Shift+F11 | 60 мс |
| Turbo | Ctrl+Shift+F12 | 30 мс |

При подготовке не используются `castDelayMs`, `clickDelayMs` и `altDelayMs`. Таблица показывает только сумму пауз между четырьмя нажатиями, без распознавания, ожидания GSI и межкомандного интервала. Реальная скорость зависит от Windows и игры.

Для ручного применения оставь слоты `slot1` и `slot2` вне списка `blockKeys`. По умолчанию блокируется только Invoke (`["invoke"]`), поэтому D и F доступны. Если раньше блокировал слоты, сними соответствующие галочки в настройках Ctrl+Shift+F9 и сохрани настройки с перезапуском приложения.

## Настройки

Файл `config.json` находится рядом с main.js. Пример:

```json
{
  "voiceChatKey": "G",
  "castMode": "click",
  "listen": "hold",
  "keys": { "quas": "Q", "wex": "W", "exort": "E", "invoke": "R", "slot1": "D", "slot2": "F" }
}
```

- `voiceChatKey` — клавиша голосового чата, в том числе MOUSE3, MOUSE4, MOUSE5.
- `castMode` — `"click"` для обычного каста, `"quickcast"` для быстрого каста.
- `listen` — `"hold"` для удержания клавиши или `"always"` для постоянного прослушивания (возможны случайные команды).
- `keys` — клавиши сфер, Invoke и слотов способностей.
- `blockKeys` — по умолчанию `["invoke"]`; `[]` отключает блокировку.
- `microphone` — название устройства; пустая строка выбирает системный микрофон.
- `expandedVocabulary` — при отсутствии параметра V2 выбирается автоматически; `false` отключает её и скачивание.
- `phrases` — свои русские варианты названий способностей.
- `port` — локальный порт, по умолчанию 3055. `authToken` — токен GSI; установщик синхронизирует его с конфигурацией игры.

Игровые интервалы по умолчанию (мс):

| Параметр | Обычный | Ускоренный | Турбо |
|---|---:|---:|---:|
| keyDelayMs | 35 | 20 | 10 |
| castDelayMs (без GSI) | 90 | 90 | 90 |
| clickDelayMs | 60 | 30 | 10 |
| altDelayMs | 30 | 20 | 10 |
| chainGapMs | 40 | 20 | 10 |
| slotWaitMs (максимум ожидания) | 1500 | 1500 | 1500 |

Турбо использует минимальный ненулевой интервал SetTimer (10 мс); фактическое время может быть больше. Паузы перед кликом и вокруг Alt в Turbo также составляют 10 мс и требуют проверки в игре. Ожидание слота и резервные 90 мс не изменены. При запуске по умолчанию обычный профиль; переключение действует на следующую ещё не начатую команду, в том числе сохраняет профиль между сборкой и применением по GSI. Очередь ждёт фактического завершения серии ввода. GSI throttle, тайм-ауты и модель не изменены. Оба экспериментальных режима требуют ручных проверок; интервалы не являются измеренной общей задержкой распознавания. Подробнее: [настройки и диагностика](docs/CONFIGURATION.md).

## Обновление и удаление

Перед обновлением закрой приложение и сохрани `config.json`, папку `model` и `.dota-install.json` (запись установки и резервная копия GSI). Не перезаписывай личные настройки. При переходе с RC3, RC4 или RC5 на RC6 исправный архив модели V2 сохраняется, повторное скачивание или пересборка модели не нужны.

Для удаления интеграции закрой приложение, запусти `uninstall.bat` и перезапусти Dota. Скрипт удаляет только отслеживаемый GSI-файл либо восстанавливает предыдущую версию. Если файл был изменён сторонним приложением, он не перезаписывается. Node.js, модель и настройки остаются на месте; после удаления GSI папку программы можно удалить вручную.

## Проверки

В [GitHub Actions](https://github.com/LuwnFM/Voice-invoker/actions) проверяются npm-зависимости, автоматические тесты, синтаксис JavaScript/HTML и PowerShell, реальное скачивание модели и SHA-256. Для RC4 автоматические тесты проверяют все 143 обычные фразы, 858 сочетаний подготовки, порядок нажатий и очередь во всех трёх профилях. Архив модели V2 проверяется и прикрепляется при публикации релиза. Работа микрофона, фактическое распознавание всех фраз в Vosk-browser, игровые задержки и установка на пользовательском ПК требуют ручной проверки.

### Выход и повторный запуск

Значок Voice Invoker в области уведомлений Windows открывает настройки и позволяет полностью выйти или перезапустить программу. Ctrl+Shift+F8 завершает приложение, закрытие Dota само по себе этого не делает. Повторный запуск открывает настройки уже работающего экземпляра. После сохранения и перезапуска настройки открываются снова. После успешной установки start.bat запускает независимый фоновый процесс и завершает свою работу: консоль можно закрыть. Журнал log.txt доступен из меню трея; вывод фонового запуска записывается в launcher.log. Для диагностики можно запустить npm start в консоли. Если порт занят другой программой или старым RC4/RC5, закрой её, не меняя порт без необходимости.

### Разрабатываемые настройки RC7

У каждой фразы своя галочка; отдельного лорного пресета нет. Список исключений хранится в disabledPhrases, применяется к обычным и подготовительным командам. Галочки сохраняются после перезапуска. Тест без нажатий и frames-per-chunk=3 выключены по умолчанию; экспериментальная модель создаётся из проверенной V2 во временной папке и не изменяет оригинал. Производительность не измерялась. Диагностика и отчёт доступны в настройках, предыдущий журнал сохраняется. Если автоматический поиск Dota не сработал, установщик запросит путь.


Первый запуск предлагает автоматически считанные бинды в форме настроек; пользователь проверяет и сохраняет их. Диагностика читает реальный процесс Dota и параметр запуска без изменения Steam; результаты могут быть неизвестны при отсутствии доступа.

### Готовая Windows-сборка

В установщике и portable ZIP уже включены Electron, Koffi, Vosk и проверенная модель V2. Node.js для их запуска не нужен. При обновлении установщик сохраняет config.json и model; при удалении сохраняет пользовательские данные и пытается восстановить прежний GSI. Для первого запуска используйте ярлык или Start Voice Invoker.bat. Исходный ZIP по-прежнему требует Node.js.

В диагностике кнопка «Проверить / восстановить GSI» после подтверждения переустанавливает только свой GSI-файл, с прежней защитой резервной копии. При неудачном автоматическом поиске предлагает выбрать папку. Игра и Steam не закрываются. При ограничениях PowerShell остаётся запуск start.bat с точечной разблокировкой. Тест без нажатий показывает итоговый текст и совпавшие команды; текст остаётся в памяти и исключается из копируемого отчёта.

### Голосовые команды предметов

Все восемь применяемых слотов (6 основных, нейтральный предмет, телепорт) имеют собственные редактируемые фразы из словаря активной модели. Пустой список отключает слот. У способности снятие всех галочек отключает её. Отдельной команды Blink нет. Назначь клавишу слота и нужный режим: только клавиша (по умолчанию) либо клавиша + клик. Любой предмет в этом слоте применяется только при свежем GSI, доступности и отсутствии перезарядки. Рюкзак не применяется. Поиск слов в настройках проверяет фактическую таблицу символов модели; неизвестные слова и точные дубликаты активных команд не сохраняются. Отключённую фразу способности можно переназначить слоту; повторное включение такой фразы вызовет конфликт. Модель не изменяется. Сохранение и перезапуск нужны для применения настроек.
