## Что говорить

Слушает одна русская модель распознавания. Английские названия говори как обычно, с русским произношением: в настройках они записаны русскими буквами.

| Способность | Что говорить |
|---|---|
| Cold Snap | «колд снэп», «колд», «холод», «заморозка», «длительная дрожь Садрона», «обрети хрупкость льда» |
| Ghost Walk | «гост волк», «походка призрака», «я ускользаю из вида», «дух летаргии», «призрак Мирота» |
| Ice Wall | «айс вол», «стенка», «ледяная стена», «бастион горести», «гибельная стена Корикса», «белая пустошь зовёт» |
| E.M.P. | «эмп», «и эм пи», «импульс», «экстрагирующий мана пульс», «пульс Шимарэ», «недоброе коловращение Эндолеона» |
| Tornado | «торнадо», «мои враги парят», «ветра», «когти Торнаруса» |
| Alacrity | «алакрити», «рвение эксорта», «ускорение», «узри истинную скорость», «заклятие стремительности Гастера» |
| Sun Strike | «сан страйк», «солнечный удар», «заклятье испепеления Харлека», «эксорт трионис» |
| Forge Spirit | «форж спирит», «форжи», «духи», «элементали горя», «хитроумные конструкции Кальвина», «разрушители из воли и брони», «союзник из ниоткуда» |
| Chaos Meteor | «хаос метеор» (или «чаос метеор»), «метеор», «котлета», «узрите тефтель», «пироклазм бездны», «огонь небес Тарака», «небесное инферно», «карносфера бездны Галларона» |
| Deafening Blast | «дефенинг бласт», «бласт», «звуковой бум», «трисферический взрыв», «оглушающее трио», «звуковой обездвиживатель Булуфонта» |
| Cataclysm | «катаклизм» |

Слов «снэп», «алакрити», «дефенинг» и «форж» в словаре модели нет, поэтому в настройках они записаны похожими по звучанию словами: `колд с нэп`, `ала кри ти`, `де фен инг бласт`, `морж спирит`. Говорить нужно как обычно.

**Cataclysm** — это Sun Strike, применённый на себя, он работает только с Аганимом. Плагин собирает Sun Strike и нажимает его клавишу с зажатым Alt (в любом режиме каста). В Dota клавишей применения на себя должен быть Alt — так стоит по умолчанию. Без Аганима плагин ничего не нажимает.

Можно назвать несколько способностей подряд в одной фразе, например «торнадо эмп метеор». Они применяются по очереди, одна сразу за другой. Каждая срабатывает сразу, как только распознана, — ни конца фразы, ни отпускания клавиши ждать не нужно. Если для следующей способности нужен Invoke, а он ещё на перезарядке, она не применится и на экране будет «Invoke на перезарядке». Распознавание работает офлайн, звук никуда не отправляется.

| Клавиши | Действие |
|---|---|
| Ctrl+Shift+F7 | включить/выключить |
| Ctrl+Shift+F8 | выход |
| Ctrl+Shift+F9 | настройки клавиш |

`config.json`:

```json
{
  "voiceChatKey": "G",
  "castMode": "click",
  "listen": "hold",
  "keys": { "quas": "Q", "wex": "W", "exort": "E", "invoke": "R", "slot1": "D", "slot2": "F" }
}
```

- `voiceChatKey` — клавиша голосового чата. Подходят те же клавиши, что в окне настроек, в том числе `MOUSE3`, `MOUSE4`, `MOUSE5`.
- `castMode` — как в Dota: `"click"` — обычный каст (плагин нажимает клавишу и кликает под курсором), `"quickcast"` — быстрый каст (только клавиша). Меняется и в окне настроек.
- `blockKeys` — какие клавиши заблокированы для игрока. По умолчанию `["invoke"]`. Чтобы нельзя было и применять уже собранные способности руками, укажи `["invoke", "slot1", "slot2"]`. Чтобы ничего не блокировать, укажи `[]`.
- `microphone` — название микрофона, как в списке окна настроек. `""` — стандартный микрофон Windows.
- `listen` — `"hold"`: слушать, пока зажата клавиша. `"always"`: слушать постоянно. Во втором режиме союзники не слышат, а случайно сказанное название сразу применит способность.
- `keys` — если клавиши в Dota другие (можно `MOUSE3`/`MOUSE4`/`MOUSE5`).
- `keyDelayMs`, `castDelayMs`, `clickDelayMs` — паузы между нажатиями (по умолчанию 35, 90 и 60 мс). `castDelayMs` работает только без данных от игры; с ними плагин ждёт появления способности в слоте (не дольше `slotWaitMs`, по умолчанию 1500 мс).
- `altDelayMs` — за сколько до клавиши Sun Strike зажимается Alt и через сколько после отпускается, для Cataclysm (по умолчанию 30 мс).
- `chainGapMs` — пауза между способностями, названными подряд (по умолчанию 40 мс). Если вторая способность в цепочке иногда не срабатывает, увеличь.
- `phrases` — свои названия способностей по-русски, см. раздел ниже.
- `port` — если порт 3055 занят. Тогда поменяй его и в файле `.cfg`.

Для OBS с захватом игры добавь источник **Browser** `http://localhost:3055/overlay.html` размером 1920×1080. Хитмаркер у курсора (и его звук) можно отключить, добавив к адресу `?aim=0`.
