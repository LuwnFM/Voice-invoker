# Voice Invoker 1.1.0-rc.2

Голосовое управление способностями Инвокера для Windows 10/11 x64. Распознавание выполняется офлайн в Electron через vosk-browser. Эта версия — **release candidate**, а не подтверждённый стабильный релиз. Автоматизация игровых действий может нарушать правила Valve; безопасность аккаунта не гарантируется.

## Установка

1. Скачай исходники RC из Releases и распакуй в отдельную папку. Установи [Node.js 22 LTS](https://nodejs.org/en/download) x64, если его ещё нет.
2. При первом запуске V2 автоматически скачивается с Google Диска и проверяется. Если хочешь установить вручную, скачай [архив V2](https://drive.google.com/file/d/1inyLlShd7d6Lql1MosCWKGdnPUvmKXZD/view) или вложение из Releases и положи в `model/vosk-model-small-ru-invoker.tar.gz`. Не распаковывай tar.gz.
3. Закрой Dota 2, если она уже запущена, и запусти `start.bat`. Скрипт проверит Node.js/npm, при необходимости установит зависимости, найдёт Dota 2 и установит GSI. Он запустит игру с `-gamestateintegration -windowed -noborder`, затем приложение. Если PowerShell блокирует локальный скрипт или папка игры недоступна для записи, исправь разрешения для локальной установки; не отключай глобальные защиты Windows.
4. В настройках проверь микрофон, клавиши и режим применения способностей. Проверяй в безопасной тестовой среде, а не в сетевом матче. В `log.txt` должно быть `Invoker V2 (SHA-256 OK)`.

Контрольная сумма V2 (SHA-256): `dcba103f27b209415fae50065d420ab59f171bff7da047f60f3801c09de8ba90`.

Если локальная V2 отсутствует или не прошла проверку, приложение пытается загрузить её заново. Если скачивание не удалось (нет сети, нет доступа, лимит Google Диска, повреждение), используется штатная модель с предупреждением. При необходимости штатная модель скачивается с сайта Vosk. После успешной загрузки повторные запуски работают офлайн. Для принудительного выбора штатной модели укажи `"expandedVocabulary": false` в config.json.

## Управление

| Клавиши | Действие |
|---|---|
| Ctrl+Shift+F7 | Включить/выключить |
| Ctrl+Shift+F8 | Выход |
| Ctrl+Shift+F9 | Настройки |
| G (по умолчанию) | Удерживать для распознавания |

Полный список команд, включая старые фонетические варианты: [docs/COMMANDS.md](docs/COMMANDS.md). Параметры микрофона, режимы работы и диагностика: [docs/CONFIGURATION.md](docs/CONFIGURATION.md). OBS: локальный источник Browser `http://localhost:3055/overlay.html` (без голосового захвата).

## Обновление и деинсталляция

Перед обновлением закрой приложение. Сохрани `config.json`, `.dota-install.json` (резервная копия GSI) и папку `model`. Не перезаписывай личный конфиг. При переносе в другую папку сохрани запись установки или предварительно запусти старый uninstall.bat.

Для удаления интеграции закрой приложение, запусти `uninstall.bat`, затем перезапусти Dota. Скрипт удаляет только отслеживаемый GSI-файл или восстанавливает его предыдущую версию. Если файл изменён сторонним приложением, он не перезаписывается. Node.js, модель, настройки и папка приложения остаются; папку программы можно удалить вручную после успешного удаления GSI. Постоянные параметры Steam и личные бинды не изменяются.

## Проверки и ограничения RC

`npm ci`, `npm test`, синтаксис JS/HTML, проверка PowerShell и зависимостей запускаются в [GitHub Actions](https://github.com/LuwnFM/Voice-invoker/actions). Проверка хеша V2, целостности архива и совпадения файлов вне графов выполнена при подготовке модели. Реальная загрузка V2 в vosk-browser, микрофон, 143 команды, установщик на пользовательском ПК и фактические задержки в игре пока не подтверждены. Не считать RC стабильной версией.
