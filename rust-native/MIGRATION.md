# Migration contract (1.1.1 → native 2.0)

Baseline: `ff689524fa1d9a7ef3aa041fd408f38dc7c1e2c1`. Original JS remains runnable; main stays on 1.1.1 until feature and behavior parity.

Method: Rust Anything 5.0.2 ran successfully in a separate read-only CI analysis of the baseline. Each future analysis resolves and logs the current published npm version once. The mandatory behavioral gate is our own 2091-case differential replay against actual JS reference functions. No automated cutover or NAPI bridge. Rust Anything cannot certify hardware or GUI parity.

| Unit | Implementation | Remaining evidence |
|---|---|---|
| Catalog, parser, recognition gate, VK, timing, sequences, VDF | Ported | Mandatory differential suite |
| Speech session, GSI state machine | Integrated | Recorded utterances and real game packet traces |
| Native Vosk, WASAPI | Integrated | Physical mic, accuracy, latency, disconnect, 16/48 kHz |

| Steam synchronization | Integrated, read-only Steam | Real account and individual item quickcast validation |
| Settings, tray, native GDI overlay, OBS | Integrated; browser settings host | Native settings window, visual parity, multi-monitor positioning |
| Persistence, diagnostics, GSI recovery | Integrated, isolated store | Real-machine scenarios |
| NSIS installer | Packaging and integration tests configured | Successful Windows install/repair/uninstall CI and manual Windows 10 test |
| Dependencies and performance | Pending final validation | Locked build, audit, CPU/RAM/latency comparison |

Decisions: Windows x64; unchanged V2 archive hash; optional frame chunk experiment; no forced Steam writes or Blink feature; original phrases/timings; separate native config store and GSI recovery record. No Node or Electron needed at runtime. Unsupported requested audio rates fall back to the device rate; no software resampling or noise suppression yet. Dry mode recognizes outside Dota without sending input; live mode requires actual dota2.exe in the foreground and is disabled by testOnly. Only an exact native configuration file can be updated by automatic binding sync. Never remove externally modified GSI files.
