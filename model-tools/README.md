# Vocabulary adaptation
The stock small Russian model does not contain all requested words. The original phrases stay in main.js. extra-phrases.json separates stock-compatible phrases (ready) from phrases requiring a rebuilt graph (pending). No new acoustic vocabulary is claimed in this commit.

The supplied runtime archive lacks the Kaldi context tree and source lexicon. Obtain the matching small Russian 0.22 compilation package from the Vosk maintainers (not the big Russian model package). Follow https://alphacephei.com/vosk/lm: add extra.txt and all legacy phrases to the compilation corpus, review G2P pronunciations and compile the dynamic graph; preserve all existing vocabulary, test the output on recorded speech and vosk-browser. Package the full compatible model into model/vosk-model-small-ru-invoker.tar.gz and set expandedVocabulary=true in config.json only after verifying every pending word and legacy phrase. Otherwise the stock model remains active. No model binaries are committed.
