# Invoker V2

Модель собрана из русского small 0.22, Kaldi 5.5.1172, OpenFst 1.8.4, OpenGRM 1.3.17, Phonetisaurus 0.3.0. Изменены динамические графы; акустическая модель сохранена. Отобраны 44 дополнительные записи произношений. Оригинальный словарь сохранён. Файл extra.txt содержит дополнительные команды приложения; при повторной сборке сохраняйте также исходный текст Vosk и 81 исходную команду. Полный архив V2 проверяется manifest-файлом. Не активируйте непроверенный граф; живое распознавание под Windows ещё предстоит протестировать. Инструкция по адаптации: https://alphacephei.com/vosk/lm.


[44 дополнительные фонетические записи V2](reviewed-stress-additions.dic). Метки 0/1 относятся к фонетическим гласным и ударению; альтернативы отобраны без автоматического включения всех кандидатов. Это дополнение, а не весь исходный словарь. Модель не переобучена. Для запуска модель должна совпадать с [manifest](../model-manifest.json). Обычный GitHub Source code ZIP не включает бинарную модель. Не использовать её как подтверждённо протестированную в vosk-browser до ручной проверки.


## Распространение RC2

Модель V2 не изменена. Источник: [Google Диск](https://drive.google.com/file/d/1inyLlShd7d6Lql1MosCWKGdnPUvmKXZD/view). Автоматическая загрузка проверяет размер и SHA-256 перед сохранением; непроверенная модель не активируется. CI проверяет реальную загрузку и передаёт проверенный архив для публикации в Releases.
