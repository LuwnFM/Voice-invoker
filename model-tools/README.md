# Invoker V2

Модель собрана из русского small 0.22, Kaldi 5.5.1172, OpenFst 1.8.4, OpenGRM 1.3.17, Phonetisaurus 0.3.0. Изменены динамические графы; акустическая модель сохранена. Отобраны 44 дополнительные записи произношений. Оригинальный словарь сохранён. Файл extra.txt содержит дополнительные команды приложения; при повторной сборке сохраняйте также исходный текст Vosk и 81 исходную команду. Полный архив V2 проверяется manifest-файлом. Не активируйте непроверенный граф; живое распознавание под Windows ещё предстоит протестировать. Инструкция по адаптации: https://alphacephei.com/vosk/lm.
